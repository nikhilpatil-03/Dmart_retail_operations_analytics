# Dmart_retail_operations_analytics
An end-to-end retail analytics project built entirely in Google Sheets and Google Apps Script.
It takes messy raw sales data, cleans it, calculates business metrics, automates the work with scripts,
and presents the results on a live dashboard.

## Business problem
A retail chain wants to know which stores, categories, states and discount levels drive sales and margin,
and where it is losing money.
